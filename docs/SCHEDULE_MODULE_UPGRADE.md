# Amore — покращення модуля «Графік»

## Мета

Перетворити технічну таблицю робочих змін на зрозумілий інструмент для пари, який одразу відповідає на три запитання:

1. Коли ми обоє найближчим часом вільні?
2. Які спільні дні вже мають плани?
3. Як швидко оновити власний графік?

## Критерії приймання етапів 1–3

- На мобільному екрані календар не має горизонтального скролу.
- Найближчий спільний вихідний видно без пошуку в сітці.
- Натискання на будь-яку дату відкриває зрозумілий опис зайнятості.
- Запропоноване й підтверджене побачення візуально відрізняються.
- У режимі редагування однозначно зрозуміло, чий графік змінюється.
- Одиночне натискання встановлює обраний стан без циклічного прокручування.
- Масове редагування не надсилає окремий UI-запит для кожної клітинки.
- Незастосований масовий вибір неможливо втратити без підтвердження.
- Усі незаповнені дні можна вибрати одним натисканням.
- З будь-якого місяця можна швидко повернутися до поточного.
- Шаблони попереджають перед заміною всього місяця.
- Наявні сценарії підтвердження та видалення побачень продовжують працювати.

## Технічні обмеження

- Модуль не підтримує погодинну зайнятість.
- Поточні етапи не змінюють таблицю `work_schedule`.
- Статуси залишаються сумісними з наявними значеннями `Р` і `Х`.
- Порожній стан фізично видаляє запис із `work_schedule`.
- Список спільних вихідних продовжує формуватися з двох позначок `Х`.
- Побачення використовують наявні статуси `pending` і `confirmed`.
- Серверне нагадування партнеру потребує окремого notification RPC і не імітується локально.
