# ADR-0236 — Кеш не переживає зміну акаунта; «Гра» — лише для пари 1

- **Статус:** Accepted
- **Дата:** 2026-09-29
- **Спирається на:** ADR-0229 (ізоляція по парах), ADR-0230
- **Зачіпає:** `src/lib/sessionReset.ts`, `src/providers/AuthProvider.tsx`,
  `src/features/_shared/useCoupleId.ts`, `src/features/game/{gameAccess.ts,GameGate.tsx}`,
  `src/components/layout/{MoreMenu,Sidebar}.tsx`, `src/app/routes.tsx`, `src/lib/queryKeys.ts`
- **Вказівка власника (2026-09-29, скрін):** «для інших пар прибери гру з
  підменю, а також для інших пар видно усі плани Діми і Лєни, головний екран
  для інших пар досі рахує кількість днів разом Діми і Лєни … при оновленні
  сторінки все стає на свої місця, але все одно підправ щоб не було витіку
  даних, гру прибери»

## Причина

База чужого не віддавала (RLS, ADR-0229) — віддавав кеш на пристрої:

- React Query в пам'яті: ключі запитів не містять пари, тож після виходу й
  входу іншою парою в тій самій вкладці екрани отримували дані попередньої,
  доки запит не оновлювався;
- localStorage: дата початку, вид, насіння, «побачені миті», кеш джерел —
  на пристрій, а не на людину (звідси «353 нові миті» на скріні).

## Рішення

`resetPortalSession()` стирає кеш запитів і всі ключі порталу (`amore:*`,
`portal_session_user_id`) у localStorage й sessionStorage, крім вибору
пристрою (тема, вигляд вішліста). Викликається при виході й при кожному
вході ІНШОЮ людиною, ніж та, що була на пристрої (`rememberUser`).

«Гра» зроблена про Діму й Лєну: пункт «Ще → Гра» (і в сайдбарі) та маршрут
`/game` — лише для пари 1; решта з `/game` потрапляє на головну. Пару питаємо
в бази (`portal_me`), поки не відомо — пункту немає.

## Перевірка

Тести `sessionReset.test.ts`: ключі пари стираються, тема лишається; кеш
запитів порожній; гра видна лише парі 1. Живі кадри: тестова пара — «Ще» без
гри, `/game` веде на головну з її даними; власник — гра на місці.

## Лишилось

Вихід-вхід двома акаунтами в одній вкладці в пісочниці не відтворено
(оснастка щоразу відкриває новий контекст) — сценарій закритий тестом.
