- **Статус:** Accepted
- **Дата:** 2026-09-27
- **Зачіпає:** `src/engine/species/crystalV2/` (новий: `hash`, `calendar`,
  `model`, `geometry` + тести), `src/features/home/crystal3d/v2/` (новий:
  `crystalV2Sources`, `crystalV2Frame`, `crystalV2Material`, `useCrystalV2`,
  `CrystalV2Object`, `CrystalV2Scene` + тести),
  `crystal3d/CrystalSceneEntry.tsx`, `evolution/useEvolutionCrystalPipeline.ts`
  (`readQuality` експортовано), `tools/crystal_twin/` (новий),
  `package.json` (`test:twin`), `scripts/quality-gate.sh`,
  `.github/workflows/ci.yml`, `docs/MODULE_STATUS.md`
- **Тип зміни:** правило росту кристала й сцена, яку бачить пара
- **Вказівка власника:** «Напиши з нуля сцену кристала і переглянь його ріст
  через модулі — чи все логічно, а лаконічно працює, перепиши сцену на
  пайтоні». Уточнення: «Python-двійник для перевірки», «Усе: і ріст, і сцену».

## Що показав перегляд

Старий ріст іде через шість томів Evolution (~16 тис. рядків): події модулів
стають абстрактним вектором тиску, з нього — композиція, геометрія, матеріал.
Результат правильний за своїми тестами, але питання власника «що дає кожен
модуль» на ньому не має короткої відповіді. Конкретні знахідки:

| # | Знахідка | Наслідок |
|---|---|---|
| 1 | Два конвеєри кристала: Evolution і лінивий аварійний `CrystalScene` з **іншими** правилами | аварія міняла б не лише вигляд, а й сенс |
| 2 | Імена «Діма»/«Лєна» зашиті в `resolveCrystalColorPartners` | лишилось; v2 бере партнерів звідти ж, заміна — окрема задача |
| 3 | Медіа датовані масово (`createdAt` імпорту) | рік імпорту роздувався; у v2 медіа дають лише сяйво |
| 4 | Події до дня початку (дні народження) падали в перший рік | у v2 все поза `[початок, сьогодні]` ігнорується |
| 5 | Одне виконане бажання фарбувало весь кристал у чистий колір | у v2 сила = відрив / (усього + 3) |
| 6 | `MODULE_STATUS.md`, колонка «У світі» відставала від ADR-0215/0216 | виправлено в цій зміні |

## Рішення: модель v2

Кожен модуль дає **рівно один** ефект, і кожен ефект має одне джерело.

| Джерело | Ефект | Формула |
|---|---|---|
| дні разом | висота монарха; ріст кожного кристала року з віком | `H = 1.4 + 1.25·ln(1+років)` |
| спогади | ширина монарха | `r = 0.40 + 0.10·ln(1+років) + 0.06·ln(1+спогадів)` |
| завершені плани | яруси вершини | `1 + min(3, ⌊log₂(1+планів)⌋)` |
| виконані бажання | колір колонії | Лєна виконує → червоний, Діма → блакитний, спільне → зелений; тягне найбільший канал, сила = відрив/(усього+3) |
| віхи календаря | іскри в кристалі свого року | одна на віху |
| місця | нахил кристала свого року назовні | `14° + 22°·частка місць` |
| медіа (переглянуті) | лише сяйво | `0.18 + 0.4·(1−e^(−медіа/40))` |
| спільні вихідні | активність року | вага 0.25 |

Кристал року: `h = H·clamp(0.14 + 0.08·ln(1+вік) + 0.045·ln(1+активність), 0.12, 0.55)`,
азимут — золотий кут `k·137.508°` + зсув із хешу, відстань `R + 0.14 + 0.09·√k`.
Ваги активності: спогад 1, план 2, бажання 2, подія 1, віха +2, місце 1.5,
медіа 0, вихідний 0.25. Власний тон пари — 260° + 14°·крок (6 кроків),
жовтого не буває за побудовою (цілі — рівно 360°, 240°, 120°).

Не живлять кристал навмисно: покупки, кулінарія, «куди піти», розміри, гра.

## Семантичні зміни проти старого рушія

- Довіра до малої вибірки в кольорі (знахідка 5).
- Медіа не впливають на розмір і на активність року (знахідка 3).
- Події поза межами історії ігноруються (знахідка 4).
- «Минуле не переписується» тепер означає: тіло кристала року незмінне;
  його відстань від монарха може рости разом із монархом.

## Геометрія й сцена

- Кожне тіло — шестигранна призма з ярусною вершиною; кільце ярусу — кільце
  нижче, стиснуте до осі, тому **кожна грань пласка за побудовою** (тест).
- Трикутники закручені назовні (тест). Перший живий кадр показав протилежне:
  передні грані відсікались, крізь монарх було видно його дальню стінку й
  ауру сцени.
- Основи заглиблені на 12% висоти; жеода — 16 битих каменів, не диск.
- Матеріал «намальований»: колір × тон грані × ключ у степені 1.7 × градієнт
  основа→вершина, кант лише на справжніх ребрах (слоти діагоналей = 1),
  відблиск лише на силуеті. Виміряно профілем на живому порталі: сусідні
  грані монарха різняться на 30% і 54% лінійного світла (поріг — 30%).
- Сцена стоїть на тому самому `PortalStage` (острів, небо, камера, жести,
  обертання у модулях) і на тій самій лінії землі; масштаб сталий (кадр
  заповнює 20-річний монарх), тож старший кристал більший на екрані.
- Ключі «що виросло» ті самі, що в старого рушія — пам'ять візиту переживає
  заміну.

## Двійник і звірка

`tools/crystal_twin` — незалежний запис того самого правила на Python
(numpy + Pillow): модель, геометрія, програмний рендер, звіт по модулях
українською і смуга росту по роках однією камерою. Він пише еталони
`golden/*.json` для фікстур; `model.test.ts` вимагає, щоб TypeScript дав те
саме з допуском 2·10⁻⁶. Спільне: хеш FNV-1a по UTF-8 + fmix32, округлення
`⌊x·10⁶+½⌋/10⁶`, цивільна арифметика днів без `Date`, 29 лютого → 28.
Тести двійника — в `npm run test:twin`, у воротах якості й у CI.

Справжній знімок пари лежить лише в `tools/crystal_twin/private/`
(`.gitignore`) і в репозиторій не потрапляє.

## Відкат

Старий конвеєр Evolution лишився в коді цілим. `CrystalV2Scene` вантажить
його ліниво, якщо v2 не змогла зібратись; повернути його назавжди — один
рядок у `CrystalSceneEntry`.

## Межі

- Живий кадр знято в SwiftShader: про частоту кадрів і тривалість нічого не
  стверджується.
- Партнери кольору досі визначаються за іменами (знахідка 2).
- Шість томів Evolution для кристала тепер лише шлях відкату; їх видалення —
  окреме рішення власника.
