# ADR-0134 — Коментар з'їв власне виправлення: на десктопі не було бічної панелі

- **Статус:** Accepted
- **Дата:** 2026-09-06
- **Зачіпає:** `src/index.css`,
  `components/layout/sidebarRule.test.ts` (новий), `docs/MODULE_STATUS.md`
- **Тип зміни за `CHANGE_CONTROL_AND_ADR.md`:** виправлення вади + нова засувка

## §1 Скарга власника

«На десктоп версії немає взагалі бокової панелі. Там видно тільки
артефакт».

## §2 Причина, підтверджена зібраним CSS

У `@media (min-width: 900px)` правило `.sidebar` мало коментар УСЕРЕДИНІ
блоку, і він закривався після першого абзацу. Решта прози лишалась голим
текстом серед оголошень.

Парсер CSS на такому пропускає все до кінця блоку. У збірці від правила
лишалось:

```css
.sidebar{z-index:50;padding:…;background:…;border-right:…}
```

Немає `display: flex`, немає `width: 240px`, немає `position: relative`.

Поза медіа-запитом стоїть `.sidebar { display: none }` — мобільний стан, —
і перекрити його стало нічим. **Тобто панелі не було не «під полотном», а
не було взагалі: `display: none` на всіх ширинах.**

Іронія в тому, що з'їдений коментар описував рівно цю ваду в її
попередньому вигляді: «на десктопі порталу не було жодної досяжної
навігації взагалі». Пояснення вади з'їло її виправлення.

## §3 Чому цього ніхто не бачив

- Типізація до CSS не доходить.
- **Збірка не падає.** Vite на цьому файлі зібрався за 3 секунди без
  жодного попередження — він просто викинув оголошення.
- Жоден тест не читав стилю.
- На телефоні все правильно: там панелі й не має бути.

## §4 Виправлення

Коментар стоїть ПЕРЕД блоком, а не в ньому. Перевірено на зібраному
файлі: `.sidebar{z-index:50;width:240px;…;flex-direction:column;display:flex;position:relative}`.

## §5 Засувка

`sidebarRule.test.ts` читає `src/index.css` справжнім парсером (postcss) і
стереже три рівні:

1. **Стиль узагалі розбирається.** На справжній формі вади postcss кидає
   `CssSyntaxError: Unknown word` — тобто він СТРОГІШИЙ за збірку, і саме
   тому годиться в засувку.
2. **Десктопне правило оголошує `display`, `position`, `z-index`,
   `width`.** Перше перекриває мобільний `display: none`; друге й третє —
   те, без чого панель є, але лежить під полотном порталу.
3. **У жодному правилі немає голого тексту серед оголошень** — загальніша
   половина тієї самої вади.

Розбір лінивий, усередині тестів: на рівні модуля виняток зробив би зі
збою «no tests» замість того, щоб назвати файл і рядок. Перевірено
мутацією — з поверненим зламаним коментарем тест падає з
`index.css:944:5: Unknown word position`.
