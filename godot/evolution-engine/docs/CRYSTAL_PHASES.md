# Godot Crystal migration phases

## Phase 1 — Deterministic vertical slice

Established the first browser-executable Crystal path:

- immutable Artifact DNA and deterministic seed;
- sorted append-only Evolution Event history;
- mother/child lineage;
- bounded collision resolution;
- procedural ArrayMesh generation;
- same-origin React iframe bridge;
- Godot 4.7.1 WebAssembly export and Pixel 8 Pro browser proof.

Phase 1 proved the architecture, not the final visual language.

## Phase 2 — Genesis druse and organic attachments

### Accepted contracts

- DNA creates one generation-zero mother and five generation-one basal crown crystals;
- basal roots are spaced around 65–88% of the mother radius;
- basal root pairs respect a deterministic minimum separation;
- event roots attach near 70–90% of the parent surface radius;
- child meshes use a flared base extended backward into the parent;
- merge depth is canonical metadata, not an ad-hoc renderer offset;
- material emission and pink fill are bounded to preserve facet readability.

### Visual acceptance

The accepted Pixel 8 Pro browser proof shows a readable druse base without the earlier central X-shaped root crowding. Phase 2 establishes attachment and foundation structure; it does not finalize morphology, optical material or foundation sculpting.

## Phase 3 — Morphology and termination grammar

### Canonical morphology parameters

Every accepted crystal instruction now owns deterministic values for:

- body taper;
- waist ratio;
- shoulder height;
- termination depth;
- facet phase;
- ring twist;
- ridge strength;
- center-axis drift;
- asymmetric tip offset.

These values belong to Species translation and are serialized with Growth Instructions. The renderer may project them but must not invent them.

### Geometry projection

The Godot mesh builder projects each crystal through five profile rings:

```text
embedded base
  → lower recovery ring
  → waist ring
  → shoulder ring
  → termination ring
  → asymmetric tip
```

Rings may twist and drift within bounded values while preserving the accepted root, direction, radius, length and lineage.

### Acceptance gates

Phase 3 must pass:

1. deterministic state reconstruction;
2. morphology parameter bounds;
3. single-surface ArrayMesh generation;
4. minimum vertical and lateral mesh extent;
5. release Web export;
6. React → Godot WebAssembly bridge proof;
7. manual Pixel 8 Pro silhouette and facet review.
