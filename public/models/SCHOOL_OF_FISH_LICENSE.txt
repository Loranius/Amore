This project uses an optimized derivative for the Amore reef scene. Geometry storage, embedded textures, PBR material representation, and animation key density were optimized for web delivery. The original authored fish school, rig, and swimming animation remain the source of the visual asset.

Changes made for web use: exact duplicate-vertex removal, texture downscaling/compression, legacy material conversion to core metallic-roughness PBR, and bounded animation curve reduction.
